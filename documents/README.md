# Исходные нормативные документы

| Файл | Документ | Редакция |
|---|---|---|
| `kodeks-o-nedrah-i-nedropolzovanii.docx` | Кодекс Республики Казахстан «О недрах и недропользовании» от 27 декабря 2017 года № 125-VI ЗРК | по состоянию на 02.03.2026 |
| `edinye-pravila-racionalnoe-kompleksnoe-ispolzovanie-nedr.docx` | Единые правила по рациональному и комплексному использованию недр (приказ Министра энергетики РК от 15 июня 2018 года № 239) | по состоянию на 21.06.2026 |

Оба документа — официальные нормативные правовые акты РК (ИПС «Әділет»).

Индексируются только части, относящиеся к **углеводородам**: разделы про добычу
урана, твёрдые и общераспространённые полезные ископаемые, старательство и
использование пространства недр исключаются фильтром тем (`app/sections.py`).
Общая часть Кодекса сохраняется — её нормы действуют и для углеводородов.

Переиндексация:

```bash
python3 scripts/index_documents.py --reset
```
