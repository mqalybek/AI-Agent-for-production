# RAG-ассистент по законодательству о недропользовании

Веб-приложение, которое отвечает на вопросы по нормативным документам о недрах
**только на основании загруженных файлов** и указывает источник каждого
утверждения (название документа + статья/пункт, при наличии — страница).

* **Backend** — FastAPI (Python).
* **Векторный поиск** — ChromaDB (persistent, косинусная метрика).
* **Генерация ответов** — Anthropic API (Claude).
* **Админ-панель** — загрузка/обновление/удаление PDF, DOCX, TXT, MD.
* **Публичный чат** — вопрос → релевантные фрагменты → ответ со ссылками.

## Важно про эмбеддинги

У Anthropic **нет собственного эндпоинта эмбеддингов** — компания рекомендует
сторонних провайдеров. Поэтому в проекте два режима векторизации
(`EMBEDDINGS_PROVIDER`):

| Значение | Что использует | Когда брать |
|---|---|---|
| `local` (по умолчанию) | `all-MiniLM-L6-v2` (ONNX) внутри chromadb | офлайн, без внешних вызовов и оплаты |
| `voyage` | Voyage AI (`voyage-3`), рекомендованный Anthropic | выше качество на русскоязычных нормативных текстах |

Генерация ответа в обоих случаях идёт через Claude.

## Быстрый старт

```bash
cd subsoil-law-rag
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# в .env укажите ANTHROPIC_API_KEY и ADMIN_TOKEN

./run.sh                       # или: uvicorn app.main:app --reload
```

* Чат — <http://127.0.0.1:8000/>
* Админ-панель — <http://127.0.0.1:8000/admin> (вход по `ADMIN_TOKEN`)
* Swagger — <http://127.0.0.1:8000/docs>

При первом запуске в режиме `local` chromadb скачает ONNX-модель (~80 МБ).

## Как это работает

1. **Загрузка.** Админ загружает файл. `app/ingest.py` вытаскивает текст
   (`pypdf` / `python-docx`) и режет его на фрагменты по ~`CHUNK_SIZE` символов.
   Заголовки вида «Статья 12», «Глава 3», «Раздел II», «3.1.2)» распознаются
   регулярками: **новая статья всегда начинает новый фрагмент**, а её номер
   пишется в метаданные — именно он потом попадает в ссылку на источник.
2. **Индексация.** `app/store.py` кладёт фрагменты в ChromaDB с метаданными
   `doc_id / title / locator / page`. Повторная загрузка того же документа
   (галочка «Обновить существующий») удаляет старые фрагменты по `doc_id` и
   индексирует заново — дублей не остаётся.
3. **Ответ.** `app/rag.py` берёт `TOP_K` ближайших фрагментов, оборачивает их в
   блок `<документы>` с атрибутами источника и отправляет в Claude с жёстким
   системным промптом.
4. **Дисклеймер.** Системный промпт требует завершать ответ строкой о том, что
   это не заменяет консультацию юриста; сервер дополнительно дописывает её,
   если модель забыла, и отдаёт отдельным полем `disclaimer`.

## Гарантии «только по документам»

* Системный промпт запрещает использовать знания модели вне переданных фрагментов.
* Если поиск не нашёл ничего — **запрос к модели вообще не отправляется**,
  пользователь получает честное «в загруженных документах нет сведений»
  (`grounded: false`).
* Каждый ответ сопровождается списком источников с процентом сходства и
  цитируемым фрагментом — ответ можно проверить глазами.
* В админке есть «Проверка поиска» — показывает, что именно достаёт ретривер,
  без вызова модели (удобно подбирать `CHUNK_SIZE` и `TOP_K`).

## API

| Метод | Путь | Доступ | Назначение |
|---|---|---|---|
| GET | `/api/health` | публичный | проверка живости |
| GET | `/api/documents` | публичный | список документов в базе |
| POST | `/api/ask` | публичный | вопрос → ответ + источники |
| GET | `/api/admin/stats` | токен | документы/фрагменты/провайдеры |
| GET | `/api/admin/documents` | токен | список с метаданными |
| POST | `/api/admin/documents` | токен | загрузка (`file`, `title`, `note`, `replace`) |
| DELETE | `/api/admin/documents/{id}` | токен | удаление документа и его векторов |
| POST | `/api/admin/search` | токен | отладка ретривера без вызова модели |

Админские запросы требуют заголовок `Authorization: Bearer <ADMIN_TOKEN>`.

```bash
curl -s http://127.0.0.1:8000/api/ask \
  -H 'Content-Type: application/json' \
  -d '{"question":"Какие основания для досрочного прекращения права недропользования?"}'
```

## Настройки (`.env`)

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | ключ Anthropic (обязателен для генерации) |
| `ANTHROPIC_MODEL` | `claude-sonnet-5` | модель генерации |
| `EMBEDDINGS_PROVIDER` | `local` | `local` или `voyage` |
| `VOYAGE_API_KEY` / `VOYAGE_MODEL` | — / `voyage-3` | для `EMBEDDINGS_PROVIDER=voyage` |
| `CHROMA_DIR` / `UPLOAD_DIR` | `./data/...` | где лежат индекс и исходники |
| `ADMIN_TOKEN` | — | пароль админки; без него админка отключена (503) |
| `CHUNK_SIZE` / `CHUNK_OVERLAP` | `1200` / `200` | нарезка текста |
| `TOP_K` | `6` | сколько фрагментов уходит в контекст |
| `MAX_UPLOAD_MB` | `40` | лимит размера файла |

Каталог `data/` в git не попадает — индекс и загруженные файлы остаются локально.

## Ограничения

* Сканы без текстового слоя не индексируются — нужен предварительный OCR
  (сервер вернёт понятную ошибку 422).
* Токен админки один на всех; для продакшена стоит завести нормальную
  аутентификацию и HTTPS-прокси перед приложением.
* Ответы — справочные. Юридическую силу имеет только официальный текст акта.
