# Запуск с нуля: от регистрации до работающего ассистента

Инструкция для того, кто ставит ассистента первый раз. Занимает минут двадцать,
из них половина — ожидание установки.

## Что здесь вообще происходит

Языковая модель не «встраивается» в проект и не скачивается на компьютер. Claude
работает на серверах Anthropic. Наше приложение при каждом вопросе:

1. ищет подходящие нормы в своей базе документов (это происходит локально,
   бесплатно и без интернета);
2. отправляет найденные фрагменты вместе с вопросом в Anthropic;
3. получает готовый ответ и показывает его со ссылками на статьи.

Значит, купить нужно ровно одно: **доступ к API Anthropic**. Это не подписка
Claude Pro за $20 — подписка даёт доступ к чату claude.ai, но не к API.
Оплачивается отдельно, по факту использования.

## Шаг 1. Ключ Anthropic

1. Зайдите на <https://console.anthropic.com> и зарегистрируйтесь (можно через
   тот же аккаунт, что и claude.ai — это разные продукты с общим входом).
2. **Plans & Billing** → пополните баланс. Минимум — 5 долларов, этого хватит
   примерно на 100–150 вопросов на модели `claude-opus-5`. Для знакомства
   достаточно; кредиты не сгорают.
3. **Settings → API keys → Create key**. Скопируйте ключ (`sk-ant-...`) сразу:
   второй раз консоль его не покажет.

Сколько стоит вопрос: в модель уходит вопрос плюс 6 найденных фрагментов
(~3000 токенов), обратно — ответ (~600 токенов). На `claude-opus-5` это около
3–5 центов. Если поставить в `.env` `ANTHROPIC_MODEL=claude-sonnet-5`, выйдет
примерно вдвое дешевле при чуть более простых формулировках.

## Шаг 2. Установка

Нужен Python 3.10 или новее (<https://www.python.org/downloads/>; на Windows при
установке отметьте «Add python.exe to PATH»).

```bash
git clone https://github.com/mqalybek/AI-Agent-for-production.git
cd AI-Agent-for-production
```

Запустите `start.bat` (Windows) или `./start.sh` (macOS, Linux). При первом
запуске скрипт создаст файл `.env` и остановится — это ожидаемо.

## Шаг 3. Заполнить .env

Откройте `.env` в блокноте. Две строки, которые нужно поменять:

```
ANTHROPIC_API_KEY=sk-ant-...     ← ключ из шага 1
ADMIN_TOKEN=придумайте-пароль    ← этим паролем вы войдёте в админ-панель
```

`ADMIN_TOKEN` — это просто пароль администратора. Никуда регистрироваться не
нужно, вы придумываете его сами: например, `neft2026-admin-kz`. Кто знает этот
пароль — может загружать и удалять документы.

Запустите `start.bat` / `./start.sh` ещё раз. Теперь скрипт поставит зависимости,
проиндексирует документы (скачается модель поиска, ~80 МБ) и запустит сервер.

## Шаг 4. Открыть

| Что | Адрес | Как войти |
|---|---|---|
| Чат для пользователей | <http://127.0.0.1:8000/> | без пароля |
| Админ-панель | <http://127.0.0.1:8000/admin> | поле «Токен администратора» → ваш `ADMIN_TOKEN` |

В админ-панели первым делом нажмите **«Проверить ключ»** в блоке «Подключение к
Claude». Возможные ответы:

| Сообщение | Что делать |
|---|---|
| Ключ работает, ответы формирует модель… | всё готово, можно пользоваться |
| ANTHROPIC_API_KEY не указан в файле .env | вписать ключ и перезапустить сервер |
| Anthropic отклонил ключ | ключ скопирован не полностью или отозван — создать новый |
| Ключ принят, но доступ к модели закрыт | пополнить баланс в Anthropic Console |

Проверка стоит доли цента: это настоящий запрос к модели, но на один токен.

## Шаг 5. Проверить на деле

Откройте чат и спросите что-нибудь по существу, например: «Какие сроки периода
разведки углеводородов?» Ответ должен прийти со ссылкой на статью Кодекса.
Разверните блок «Источники» и убедитесь, что норма процитирована та самая.

Дальше можно уточнять («а если это сложный проект?») — ассистент помнит разговор.
Если ответ неверный, нажмите **👎 Неверно** и напишите, что не так: замечание
попадёт в админ-панель, в раздел «Оценки пользователей».

## Шаг 6. Свои документы

Админ-панель → «Загрузить документ». Поддерживаются PDF, DOCX, TXT, MD.

Важное поле — **«Название документа»**: именно оно попадёт в ссылку на источник,
поэтому пишите так, как принято ссылаться: «Кодекс РК «О недрах и
недропользовании»», а не «kodeks_final_v2».

Галочки «Не индексировать разделы по темам» отсекают лишнее: для ассистента по
углеводородам разделы про уран и твёрдые полезные ископаемые — шум, который
только мешает поиску.

## Дальше: чтобы работало не только на вашем ноутбуке

Пока сервер запущен на вашей машине, ассистент доступен только на ней. Чтобы им
пользовались коллеги, приложение нужно поставить на сервер — см. раздел «Если
нужен доступ для коллег» в README.md.
